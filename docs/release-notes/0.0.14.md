## What's new

### History

- Open **Find** (`⌘F` or `Ctrl+F`) in History and choose **Commits** to
  search by message or by a hash prefix of at least four hexadecimal digits. The
  search covers the selected branch, tag, or graph scope, including commits
  you have yet to scroll to. Choose a result to open it in the graph and see
  its changed files and diff. **Files** still opens the history of a file.

### Accounts and cloning

- **Settings > Accounts** shows saved HTTPS logins and supports multiple
  accounts per host. Use **Refresh** to check credentials against repositories
  you have open. Token setup includes guidance for GitHub, GitLab, Bitbucket,
  Gitea and Azure DevOps. Git's credential helper keeps the tokens available
  to terminal git.
- **Clone by URL** suggests a folder under `~/gf-workspace` and updates the
  suggestion as you edit the URL. Set a different default in **Settings >
  Tools**, or enter a destination for just that clone.

### Worktrees

- Linked worktree tabs show the project name alongside the current branch
  or short commit hash. This makes tabs recognizable even when their folders
  have custom names.
- The Worktrees panel highlights the current worktree's marker and dims the
  markers for worktrees open in other tabs.
- Shared file warnings count each overlapping path once, including files in
  untracked directories and in large change sets. Changes already present in
  the base after a squash merge are left out.
