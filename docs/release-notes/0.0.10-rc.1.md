## What's new

- **Log in to git servers from Settings.** A new ACCOUNTS section logs in and
  out of HTTPS git servers. Tokens go to git's own credential helper, so gf
  and terminal git share the same logins; gf only remembers the protocol,
  host and user name. Each login shows its service, whether the token is still
  stored (a token the server refused shows a warning and "Log in again"), and
  which open repositories use it.
- **Authentication failures retry after login.** Fetch, pull, push, publish,
  force push, tag push, submodule update, LFS pull and raw git commands that
  fail on authentication open a login dialog for that server and retry once
  you are logged in.
- **Clone by URL.** The repository picker (⌘O) accepts a URL and clones it into
  a folder you choose. Clones run in the background with progress in the status
  line, and Esc cancels one (the partial folder is removed).
- **Settings is split into sections** (ACCOUNTS, APPEARANCE, TOOLS,
  CONFIRMATIONS), switched with ↑/↓, ⌘1–⌘5 or a click. A warning above every
  section tells you when git is missing.
- **Compare a branch with the current one.** The branch menu has "compare with
  current" (c), which shows the diff from the checked-out commit to that
  branch's tip.

## Try this pre-release

`install.sh` on the latest release does not pick up pre-releases. This release
carries its own installers, which need no argument:

```bash
curl -fsSL https://github.com/tom-kwak/GitFast/releases/download/release-0.0.10-rc.1/install.sh | bash
```

On Windows, run `irm https://github.com/tom-kwak/GitFast/releases/download/release-0.0.10-rc.1/install.ps1 | iex` in PowerShell.
