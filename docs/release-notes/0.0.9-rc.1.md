## What's new

- **Separate macOS downloads for Apple silicon and Intel.** The universal
  `.dmg` is replaced by `gf-macos-arm64.dmg` and `gf-macos-x86_64.dmg`, each
  built natively on its own architecture. `install.sh` picks the one for your
  Mac; to install by hand, download the one that matches it.
- **Pre-releases stay out of "latest".** A version with a suffix such as
  `0.0.9-rc.1` is published as a pre-release, so `install.sh` keeps
  installing 0.0.9.

## Try this pre-release

`install.sh` on the latest release does not pick up pre-releases. This release
carries its own installers, which need no argument:

```bash
curl -fsSL https://github.com/tom-kwak/GitFast/releases/download/release-0.0.9-rc.1/install.sh | bash
```

On Windows, run `irm https://github.com/tom-kwak/GitFast/releases/download/release-0.0.9-rc.1/install.ps1 | iex` in PowerShell.
