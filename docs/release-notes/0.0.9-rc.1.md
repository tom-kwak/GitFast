## What's new

- **Separate macOS downloads for Apple silicon and Intel.** The universal
  `.dmg` is replaced by `gf-macos-arm64.dmg` and `gf-macos-x86_64.dmg`, each
  built natively on its own architecture. `install.sh` picks the right one.
- This is a pre-release: it is not marked as the latest release, so
  `install.sh` keeps installing 0.0.9. To try it, pass its `.dmg` URL in
  `GF_DMG_URL`.
