## What's new

### Three-way conflict editor

- Resolve merge, rebase and cherry-pick conflicts in an editor that aligns
  both sides with an editable result in the middle. Take either side or
  combine both sides in either order for each conflict block.
- Move between unresolved blocks or inspect individual differences within a
  block. Drafts are kept while you switch between conflicted files.
- Before saving, gf checks that the working copy and index still match what
  you opened. A successful save stages only the resolved file.
