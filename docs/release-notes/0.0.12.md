## What's new

### Worktrees

- **New worktrees get your local files.** A new worktree is a fresh
  checkout, so git-ignored files such as `.env` are missing from it. When the
  repository has a `.worktreeinclude` at its root, gf copies the ignored files
  it lists into each new worktree, as Claude Code and Conductor do. Only files
  git ignores are copied, a file already in the new tree is kept, and nothing
  is written through a linked folder.
- **The copy runs after the worktree opens**, so a large ignored folder such
  as `target/` no longer holds the new tab back. Copied files, kept files and
  failures each get their own entry in the command log.
- Settings > Tools > New worktrees turns the copy off and on
  (`worktrees.copy_included`, on by default).

### History

- **All branches no longer shows stash commits.** The `WIP on` / `index on`
  commits of the newest stash, and commits a reset or rebase dropped that
  only a stash still held, are gone from the graph; stashes stay in the refs
  panel. Notes, `git maintenance` prefetch refs and `refs/original/` are left
  out the same way.
- Stashing and popping no longer reload the history.
