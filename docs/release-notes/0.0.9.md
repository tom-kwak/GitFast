## What's new

- **Much faster, lighter history on big repositories.** Loading more commits
  reads only the next page instead of the whole history again, and the graph
  keeps only what it draws. On git.git (83k commits) scrolling to the end
  went from 49 s to 18 s and the history's memory from about 1 GB to 135 MB.
- **Large diffs wait until asked.** A file whose diff is over 20,000 lines or
  1 MiB shows a notice instead; Enter or "show diff" draws it. Diffs past
  32 MiB are refused, so one huge file no longer stalls gf.
- **Refs panel**: drag its edge to resize it (double-click resets, the width
  is remembered). Rows are indented under their section label, and cut names
  show their full text in the tooltip.
- **Worktrees panel** closes like REFS (`«`); when the panel is closed, REFS
  and WORKTREES strips at the top reopen either one.
- Checking out a branch that another worktree holds now offers to go to that
  worktree's tab instead of failing with git's error.
- Tags are listed newest version first (`v1.10.0` above `v1.2.0`), other
  names after them in natural order.
- The history row hover lists the refs folded into `+N`, and the details box
  shows every ref on the commit.
- Removed worktrees drop out of the recent list.
- Worktree status, the default base and undo snapshots are read in process
  (gitoxide) instead of running 6-12 git processes per tree.
- Fixed: undo and reflog resets failed on git 2.43.
