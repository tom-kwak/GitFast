## What's new

- **Worktree cards say what each tree is up to.**
  - Each card hangs from a title that names the branch it merges into and
    how it stands against it: `main ← 3 to merge · 3 new`, or
    `main ← all merged`. The tree on the base itself has no title.
  - One word on the name's line gives the tree's state: `EDITING` (files
    changed in the last 2 minutes), `UNCOMMITTED`, `READY`, `MERGED`,
    `BEHIND`, `CLEAN`, or `CONFLICT` / `MISSING` / `ERROR`.
  - The next lines show uncommitted changes and files other worktrees change
    too (`3 uncommitted · ⚠ 1 shared`), then the upstream distance (`↑2 ↓1`,
    `⊘` when never pushed) with the last commit.
  - Most text is dim. Color marks the names, the state word, and what needs
    attention.
- **Worktrees added in one tab show in the other worktrees' tabs** without
  ⌘R. A tab in the background reads the change once you switch to it.
  A `git worktree add` run in a terminal also shows in the main worktree's
  tab.

## Try this pre-release

`install.sh` on the latest release does not pick up pre-releases. This release
carries its own installers, which need no argument:

```bash
curl -fsSL https://github.com/tom-kwak/GitFast/releases/download/release-0.0.10-rc.3/install.sh | bash
```

On Windows, run `irm https://github.com/tom-kwak/GitFast/releases/download/release-0.0.10-rc.3/install.ps1 | iex` in PowerShell.
