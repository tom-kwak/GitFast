## What's new

- **Worktrees are easier to start, update, merge and clean up.**
  - The branch menu has "new worktree…" (w), which opens the dialog with that
    branch and its folder filled in.
  - A worktree card has "update from <base>…" (u), which brings in the
    commits its base has. It merges, or rebases when `git pull` would there;
    a checkbox overrides it.
  - Merging a worktree into its base can then remove the worktree and its
    branch, when the merge ends without conflicts.
  - Cards flag files that other worktrees change too (⚠n, with the files in
    the tooltip).
  - The worktrees panel highlights the tree the current tab shows.
- **A linked worktree no longer takes its base branch.** Switching a linked
  worktree to the branch its work goes back into offers to view it detached,
  or to open the main worktree, instead of holding that branch.
- **Drag tabs to reorder them**, like browser tabs. ⌘⌥⇧[ / ⌘⌥⇧] move the
  active tab one place left / right. The order is kept with the open tabs.
- **A narrower history graph.** Lines to parents more than 50 rows below are
  cut into a short arrow: the row shows ↓ and the parent, and the parent shows
  ↑N for the lines that were cut. In git.git the median graph width drops
  from 204 lanes to 2.
- **Filters match what you type, not scattered letters.** Find File, the open
  window and the tab list match the text as typed, or pieces that start words
  ("dvm" still finds `diff_view/mod.rs`).
- **Log-in dialog**: the hosting service is asked only when the server's name
  does not tell it, a guess can be changed per host, and the button to get a
  token sits beside the token field.
- **Dropdown lists in dialogs close** when you press anywhere else.
- **Faster opening of repositories without submodules.** gf no longer runs
  `git submodule status` (a script that starts about eight git processes)
  when the repository has no submodules, on open and on every refs reload.

## Try this pre-release

`install.sh` on the latest release does not pick up pre-releases. This release
carries its own installers, which need no argument:

```bash
curl -fsSL https://github.com/tom-kwak/GitFast/releases/download/release-0.0.10-rc.2/install.sh | bash
```

On Windows, run `irm https://github.com/tom-kwak/GitFast/releases/download/release-0.0.10-rc.2/install.ps1 | iex` in PowerShell.
