## What's new

- **gf now runs on Windows.** Windows 10 1809+ and 11 (x64) get the same app
  as macOS: history, working tree, diffs, blame, conflicts, interactive
  rebase, undo and tabs. Install it from PowerShell with one line (below).
- On Windows, shortcuts use Ctrl and are shown as `Ctrl+Shift+Z` instead of
  `⌘⇧Z`. Ctrl+Tab switches tabs, and "reveal in File Explorer" shows a file in
  its folder.
- On Windows, gf draws text in Cascadia Mono (Consolas where it is missing),
  finds Git for Windows even when it is not on `PATH`, and runs git without
  console windows popping up.
- When git cannot be started, the start screen says so, with a Download Git
  button and how to point gf at git in the settings.
- The open-repository window takes Windows paths such as `C:\src\gf` and
  `\\server\share`, and `~` means your user folder on every platform.
- **Worktrees view** (`⌘⇧B` beside REFS): one card per working tree, for
  watching several at once (e.g. one per AI agent). Each card shows the
  branch, uncommitted changes, files touched in the last two minutes (`⚡`)
  and, in words, where it came from: `from develop · 3 ahead · 1 behind`, or
  `merged`. Right-click for everything: open it in a tab, IDE or terminal,
  compare it with its base, **merge it into its base**, set the base,
  lock, remove. `+` adds a tree, picking the branch from a dropdown;
  `clean N` removes trees already merged.
- A tree's base is the branch it was made from (gf remembers it; otherwise
  it reads git's record or takes the nearest of main / develop / …), not
  always `main`.
- Undo / redo is safer: undoing commits already pushed warns, a restore is
  all or nothing, saved copies survive `git gc`, the redo stack survives a
  restart, and LFS track / untrack and submodule updates can be undone.
- macOS behaves as before.
