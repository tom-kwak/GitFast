## What's new

- **gf now runs on Windows.** Windows 10 1809+ and 11 (x64) get the same app
  as macOS: history, working tree, diffs, blame, conflicts, interactive
  rebase, undo and tabs. Install it from PowerShell with one line (below).
- On Windows, shortcuts use Ctrl and are shown as `Ctrl+Shift+Z` instead of
  `⌘⇧Z`. Ctrl+Tab switches tabs, and "reveal in File Explorer" shows a file in
  its folder.
- On Windows, gf draws text in Cascadia Mono (Consolas where it is missing),
  finds Git for Windows even when it is not on `PATH`, and runs git without
  console windows popping up.
- When git cannot be started, the start screen says so, with a Download Git
  button and how to point gf at git in the settings.
- The open-repository window takes Windows paths such as `C:\src\gf` and
  `\\server\share`, and `~` means your user folder on every platform.
- **Worktrees view** (`⌘⇧B`, `Ctrl+Shift+B` on Windows, beside REFS): one
  card per working tree, for watching several at once, e.g. one per AI agent.
  - Each card shows the branch, what is uncommitted (`●3`, `✕2` conflicts),
    files touched in the last two minutes (`⚡`), locked, and in words where
    the tree came from: `from develop · 3 ahead · 1 behind`, or `merged` once
    its work is in that branch.
  - Right-click (or `.`) for everything: open it in a tab, your IDE or a
    terminal, compare it with its base, **merge it into its base**, set the
    base, reveal or copy its folder, lock, remove.
  - `+` adds a tree; the branch field is a dropdown of the existing branches
    (an existing one is checked out, a new name makes a new branch).
    `clean N` removes the trees already merged, `prune` forgets the ones
    whose folder is gone.
- A tree's base is the branch it was made from, not always `main`: gf
  remembers it when it makes the branch, otherwise it reads git's record, or
  takes the nearest of `main` / `develop` / … and says it is a guess. `b`
  sets it by hand.
- **Undo / redo is safer.** Undoing commits already pushed warns first, a
  restore is all or nothing, saved copies survive `git gc`, the redo stack
  survives a restart, and LFS track / untrack and submodule updates can be
  undone.
- macOS behaves as before.
