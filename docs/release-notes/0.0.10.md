## What's new

### Worktrees

- **Cards say what each worktree is up to.** Each card hangs from a title
  naming the branch it merges into and how it stands
  (`main ← 3 to merge · 3 new`, `main ← all merged`). One word gives its
  state (`EDITING`, `UNCOMMITTED`, `READY`, `MERGED`, `BEHIND`, `CLEAN`,
  `CONFLICT`), then its uncommitted files, files other worktrees change too
  (`⚠ 1 shared`), and the upstream distance (`↑2 ↓1`) with the last commit.
- **Easier to start, update, merge and clean up.** The branch menu has "new
  worktree…" (`w`). A card has "update from <base>…" (`u`), which merges or
  rebases the base's new commits into it. Merging a worktree into its base can
  then remove the worktree and its branch.
- **A worktree added in one tab shows in the other worktrees' tabs** without
  ⌘R, and a `git worktree add` from a terminal shows in the main worktree's tab.
- **A linked worktree no longer takes its base branch.** Switching it to the
  branch its work goes back into offers to view that branch detached, or to
  open the main worktree.

### Git logins and clone

- **Log in to git servers from Settings.** Tokens go to git's own credential
  helper, so gf and terminal git share the same logins. Each login shows its
  service, whether its token is still stored, and which open repositories use
  it. The hosting service is asked only when the server's name does not tell.
- **Authentication failures retry after login.** Fetch, pull, push, tag push,
  submodule update, LFS pull and git commands typed on the `gf ❯` line open a
  login dialog for that server when they fail on authentication, and retry.
- **Clone by URL.** The repository picker (⌘O) accepts a URL and clones it in
  the background, with progress in the status line; Esc cancels.

### Everyday use

- **Settings is split into sections** (ACCOUNTS, APPEARANCE, TOOLS,
  CONFIRMATIONS) and warns above every section when git is missing.
- **Compare a branch with the current one** from the branch menu (`c`).
- **Drag tabs to reorder them.** ⌘⌥⇧[ / ⌘⌥⇧] move the active tab.
- **A narrower history graph.** Lines to parents more than 50 rows below are
  cut into arrows (`↓` on the row, `↑N` on the parent). In git.git the median
  graph width drops from 204 lanes to 2.
- **Filters match what you type**, or pieces that start words ("dvm" finds
  `diff_view/mod.rs`), not scattered letters.
- **Dropdown lists in dialogs close** when you press anywhere else.
- **Faster opening of repositories without submodules**: gf no longer runs
  `git submodule status` when the index has none.

### Downloads

- **Separate macOS downloads for Apple silicon and Intel**
  (`gf-macos-arm64.dmg`, `gf-macos-x86_64.dmg`), each built natively.
  `install.sh` picks the one for your Mac.
- **Pre-releases stay out of "latest"**, so `install.sh` installs only
  released versions.
